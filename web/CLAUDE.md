# web Module

## Role
The deployed Lambda Web Function (Node.js 24, ESM). Serves the UI, authenticates `/api/*`, creates BMA
sessions (or the optional Converse path), streams public text deltas as SSE, stores normalized results
in the us-east-1 app S3 bucket, renders reports, and runs operations investigations via a worker Lambda.

## Key Files
- `index.js` → `server.js` `createApp()` — routes, Bearer auth, 2 concurrent `/api/chat` streams max
- `investigation-routes.js` — `/api/procedures`, `/api/investigations/**`; `investigations.js` service; `investigation-worker.js` (async Lambda handler), `investigation-executor.js`, `investigation-store.js`, `investigation-records.js`
- `bma.js` (`BmaClient`), `converse.js` (`ConverseRunner`, `RuntimeMcp`), `runners.js` (`SampleRunner`, `LiveRunner`)
- `evidence.js`, `presentation.js` (account masking), `reports.js`, `report-rendering.js`, `office-reports.js` (DOCX/PPTX), `resource-insights.js`, `procedures.js`
- `stores.js` (`MemoryStore`, `S3Store`), `history.js`, `history-migrate.js`, `settings.js` (`settingsFromEnv`)
- `ui/*.js` — React sources bundled by `build-ui.mjs` into `../webapp/static/app.js`
- `contract.json`, `sample-data.json` — generated by `scripts/export_web_contract.py`; do not hand-edit

## Rules
- Edit `web/ui/*.js`, never `webapp/static/app.js`; rebuild with `npm run build --prefix web`.
- Only `web/*.js`, `package*.json`, `contract.json`, `sample-data.json`, production `node_modules` and `webapp/static/**` enter the ZIP (`scripts/build_web.py`). New runtime files must be top-level `web/*.js`.
- Never emit or persist reasoning, analysis or raw `command_execution` items; strip `bma_session_id` from client responses.
- Mask account IDs (last 3 digits) in every rendered output via `presentation.js`.
- New or changed route → update `docs/api-reference.md` and add a `web/tests/*.test.js` case.
- Keep dependency versions exact; run `npm test --prefix web` (node:test) before finishing.
- The app is served through CloudFront: only anonymous `/` and `/static/*` responses may carry public `Cache-Control`; everything else stays `no-store`. Static asset names are not content-hashed, so invalidate the distributions after a release (`docs/runbooks/cloudfront-oac.md`).
- `studio/` reuses `bma.js`, `contract.json` and production `node_modules` in its own ZIP (`studio/scripts/build_web.py`); after changing `bma.js`, also run `node --test studio/tests/backend.test.js`.
